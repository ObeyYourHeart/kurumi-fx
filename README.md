## 玩法

- **一局三个月**：每个月走 交易日 → 事件 → 交易日 → 商店 → Boss，共 9 个交易日，房租一个月比一个月贵。
- **只有三个按钮**：卖出、平仓、买入。每按一下 1 手，下单不用确认；止损、止盈可以直接在 K 线图上拖。
- **五个品种一起动**：美元/日元、纳指期货、黄金、原油、比特币共用一个保证金账户。同一条新闻会同时牵动它们：美国 CPI 超预期，美日涨、纳指跌、黄金跌；避险来了，日元和黄金一起涨。
- **新闻有"预期 vs 实际"**：经济日历提前告诉你什么时候公布、市场预期多少。超预期决定方向；事前抢跑、结果又符合预期，就是利好出尽。
- **心态会替你下单**：浮盈让人贪婪（手滑多开），浮亏让人恐惧（犹豫砍仓），连亏会上头（偷偷撤掉止损）。
- **真实的交易细节**：杠杆和维持率（跌破 50% 强制平仓）、每天换日的掉期（周三算三天）、黄金原油的持仓费、比特币每 8 小时的资金费率、央行利率决议和缩表。
- **Boss 关改编自真实的历史行情**：雷曼冲击、疫情熔断、套息平仓、财务省干预、英镑闪崩、负油价、FTX 暴雷、硅谷银行……结算时揭晓原型是哪一年的哪件事。
- **Roguelike 成长**：18 种遗物（海外FX账户、止损纪律、OPEC 内线……）和 4 种操作强化，每局的组合都不一样。
- **没钱了还有爸爸**：可以找爸爸借钱续命，但要分期还。

## 小技巧

- **种子**：同一个种子就是同一段行情，发给朋友比谁赚得多。
- **键盘**：`B` 买、`S` 卖、`C` 平仓、`Space` 走 / 停、`L` / `T` 止损止盈、`A` 梭哈、`1`–`9` 切品种。
- **红涨绿跌 / 绿涨红跌**：首页和菜单里都能切换。
- **存档**：每根 K 线自动保存在浏览器里（iPhone 上从桌面图标打开和在 Safari 里打开是两份存档）。
