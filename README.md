# FX战士 久留美姐妹 · 试玩版

同人网页小游戏：三个月、每个交易日都要交房租的 K 线 roguelike。

**在线玩：https://obeyyourheart.github.io/kurumi-fx/**

- 电脑：用浏览器打开，键盘操作（B 买 / S 卖 / C 平仓 / 空格 开盘）。
- 手机：横过来玩。iPhone 用 Safari 打开 →「分享」→「添加到主屏幕」，从桌面图标打开就是全屏。
- 存档在各自的浏览器里（从主屏幕图标打开和在 Safari 里打开是两份存档）。
